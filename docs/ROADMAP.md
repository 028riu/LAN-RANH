# Development roadmap

## Phase 1 — 3D foundation
- [x] Vite + PlayCanvas Engine project
- [x] Procedural starter island
- [x] Third-person camera
- [x] WASD movement, sprint and jump
- [x] Basic desktop and mobile controls
- [ ] Test on desktop and mobile browsers
- [ ] Improve player model and animation

## Phase 2 — Exploration
- Terrain and coastline improvements
- Multiple islands and ocean travel
- Interactable NPCs and discovery markers
- Save/load player progress

## Phase 3 — Core gameplay
- Quest objectives and rewards
- Enemy AI and combat loop
- XP, levels, stats and equipment
- Original elemental/fruit-inspired abilities

## Phase 4 — Adventure systems
- Inventory, shops and crafting
- Boats and island travel
- Boss encounters and dungeons

## Phase 5 — Online foundations
- Server-authoritative player state
- Accounts and persistence
- Multiplayer synchronization
- Abuse prevention and server validation

Multiplayer is intentionally not simulated in the first client-only prototype.
