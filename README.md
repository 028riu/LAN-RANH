# Fruit Game ZRT

A browser-based 3D action-adventure prototype built with PlayCanvas Engine, Vite, and JavaScript.

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Run locally
```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Use WASD to move, Shift to sprint, and Space to jump.

## Build
```bash
npm run build
npm run preview
```

## Project status
Phase 1: playable 3D island prototype. Future systems (quests, enemies, abilities, inventory, boats, multiplayer) will be added as separate modules.

## Credits and assets
The initial prototype uses procedural primitive geometry and generated colors; no third-party game assets are included.
